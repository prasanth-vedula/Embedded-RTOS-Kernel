# Code of Conduct

## Our Commitment

We are committed to providing a welcoming, respectful, and inclusive environment for everyone participating in this project.

---

## Expected Behavior

Participants are encouraged to:

- Be respectful.
- Be constructive.
- Welcome new contributors.
- Share knowledge openly.
- Accept feedback professionally.

---

## Unacceptable Behavior

The following behaviors are not acceptable:

- Harassment
- Personal attacks
- Discrimination
- Offensive language
- Spam
- Intentional disruption of discussions

---

## Responsibilities

Project maintainers are responsible for maintaining a professional and respectful community.

They may remove or reject content that violates this Code of Conduct.

---

## Scope

This Code of Conduct applies to:

- GitHub Issues
- Pull Requests
- Discussions
- Project Documentation
- Community interactions

---

## Enforcement

Instances of unacceptable behavior may result in warnings, removal of content, or restriction from participating in the project.

---

## Acknowledgement

This Code of Conduct is inspired by established open-source community standards and is intended to encourage respectful collaboration.
